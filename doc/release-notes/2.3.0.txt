KWIVER 2.3.0 Release Notes
=================================

This is a minor release of KWIVER that provides new functionality, fixes over
the previous v2.2.0 release, and marks outdated features for deprecation.

Updates
-------

Vital: algo

* Deprecated video_input.metadata_map().

Vital: Types

* Added utilities to local_tangent_space.

* Deprecated local_cartesian in favor of local_tangent_space.

* Deprecated local_geo_cs in favor of local_tangent_space.

* simple_metadata_map.get_item() now returns an invalid metadata object
  instead of throwing an exception, to be consistent with metadata.find().

Vital: Python

* Added local_tangent_space binding.

Arrows - VXL:

* Removed vidl_ffmpeg_video_input implementation of video_input algorithm.

Track Oracle

* Deprecated track_oracle.
