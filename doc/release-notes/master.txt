KWIVER 2.2.0 Release Notes
=================================

Updates
-------

Arrows: Core

* Added image_io_tiled_multifile.

* Permitted calculation of pseudo-VNIIRS when an image object is not provided.

Arrows: Geocalc

* Standardized behavior when given nonfinite input values.

* Added derive_corner_points.

Vital: Types

* Added tiled_image_container.

* Added tiled_image_container_simple.

Bug Fixes
---------

Arrows: Core

* Restored "homography" feature matching implementation name to
  "homography_guided".

* Better handled noncontiguous frames in track_features_core.

Arrows: GDAL

* Prevented segfault when saving image with null metadata.
