KWIVER 2.2.0 Release Notes
=================================

Updates
-------

Arrows: Ceres

* Connect Ceres built-in logging to KWIVER logging.

* Added support for interface changes in Ceres v2.

Arrows: Core

* Added image_io_tiled_multifile.

* Permitted calculation of pseudo-VNIIRS when an image object is not provided.

Arrows: FFmpeg

* Added format_name config option.

Arrows: Geocalc

* Standardized behavior when given nonfinite input values.

* Added derive_corner_points.

Python

* Added automatic .pyi stub generation.

Vital: Algo

* Change video_input timeout parameter type to microseconds instead of seconds.

Vital: Exceptions

* Omit file information from exception description when creating Release build.

Vital: Logging

* Improved format of log messages.

Vital: Types

* Added tiled_image_container.

* Added tiled_image_container_simple.

Vital: Utils

* Added catch_sigint().

Bug Fixes
---------

Arrows: Core

* Restored "homography" feature matching implementation name to
  "homography_guided".

* Better handled noncontiguous frames in track_features_core.

Arrows: GDAL

* Prevented segfault when saving image with null metadata.

CMake

* Fixed Cygwin detection in Python utilities.
